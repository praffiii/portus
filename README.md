# Portus

Activity Monitor for your dev stack.

Portus is a macOS-first Tauri v2 + Svelte app that will show and control local
ports, processes, and Docker containers from a menu-bar popover.

## Development

```bash
pnpm install
pnpm tauri dev
```

## Checks

```bash
pnpm check
pnpm build
pnpm tauri build
```
